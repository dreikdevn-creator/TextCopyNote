# TextCopyNote

Простая бесплатная программа для сохранения выделенного текста.

Выделите текст в браузере → нажмите **Alt+Z** → текст автоматически сохраняется в текстовый файл.

## Возможности

- Сохранение выделенного текста по горячей клавише **Alt+Z**
- Автоматическое добавление новых фрагментов
- Сохранение текста после каждого копирования
- Данные не теряются при отключении компьютера
- Поддержка Chrome / Chromium
- Поддержка Firefox
- Полностью бесплатно
- Без рекламы

## Как пользоваться

1. Запустите `TextCopyNote.exe`.
2. Установите расширение для своего браузера.
3. Выделите нужный текст.
4. Нажмите **Alt+Z**.
5. Текст будет сохранён в файл.
6. При следующем использовании новый текст добавится автоматически.
