TextCopyNote
==============================

НАЗНАЧЕНИЕ

TextCopyNote позволяет сохранять выделенный текст
в выбранный TXT-файл с помощью комбинации Alt+Z.

Ctrl+C использовать не нужно.


ПЕРВЫЙ ЗАПУСК

1. Запустите TextCopyNote.exe.

2. Нажмите «Выбрать TXT-файл».

3. Выберите существующий TXT-файл.

   Если файла нет — создайте обычный текстовый
   файл через Блокнот.


УСТАНОВКА ДЛЯ FIREFOX

1. Откройте Firefox.

2. В адресной строке введите:

   about:debugging#/runtime/this-firefox

3. Нажмите «Загрузить временное дополнение».

4. Откройте папку:

   Firefox

5. Выберите файл:

   manifest.json

После этого расширение будет загружено.


УСТАНОВКА ДЛЯ CHROME

1. Откройте Chrome.

2. В адресной строке введите:

   chrome://extensions/

3. Включите «Режим разработчика».

4. Нажмите «Загрузить распакованное расширение».

5. Выберите папку:

   Chrome


КАК ПОЛЬЗОВАТЬСЯ

1. Откройте нужную страницу.

2. Выделите нужный текст мышкой.

3. НЕ нажимайте Ctrl+C.

4. Нажмите:

   Alt+Z

5. Текст автоматически добавится
   в выбранный TXT-файл.


ВАЖНО

Каждое новое сохранение добавляется
в конец TXT-файла.

Предыдущий текст не удаляется.

После каждого сохранения программа
принудительно записывает данные на диск.

TextCopyNote также запоминает выбранный
TXT-файл между запусками программы.


ЕСЛИ ПОЯВИЛОСЬ «ТЕКСТ НЕ ПОЛУЧЕН»

Убедитесь, что:

1. Текст действительно выделен.
2. Вы не нажимали Ctrl+C перед Alt+Z.
3. Расширение браузера установлено и работает.
4. TextCopyNote.exe запущен.


ГОРЯЧАЯ КЛАВИША

Alt+Z
